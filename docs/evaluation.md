## Reproducing / comparing providers

This report reflects whichever `EMBEDDING_PROVIDER` was active when it was generated (see the heading above). To compare tiers, re-run with each one configured -- results will overwrite this file, so copy it aside if you want to keep more than one:

```bash
EMBEDDING_PROVIDER=offline python scripts/evaluate.py
EMBEDDING_PROVIDER=local  python scripts/evaluate.py   # needs the local-ml extra
EMBEDDING_PROVIDER=openai python scripts/evaluate.py   # needs OPENAI_API_KEY
```
